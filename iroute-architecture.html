iRoute Routing Engine Architecture

Versioned decision-tree routing for PSP/PGSP selection

Request Flow

  • • Merchant app submits payment intent to API Gateway
  • • AuthN/AuthZ validates merchant token and scopes
  • • Routing API enriches context and evaluates rules
  • • Ranked PSP/PGSP list returned; decision event emitted

Rule Lifecycle

  • • Business Portal edits decision tree nodes
  • • CI validates schema, tests, builds signed package
  • • Artifact uploaded to object store; metadata registered
  • • Active pointer updated; services reload via cache invalidation

Resilience

  • • Stateless services scale horizontally
  • • In-memory rule cache with fallback to previous package
  • • Circuit breakers for enrichment and object store
  • • Default rules embedded for store outage scenarios
